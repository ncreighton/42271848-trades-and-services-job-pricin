# Trades and Services Job Pricing Calculator and Scheduling Telegram Bot

A Telegram bot for plumbers, electricians, HVAC techs, and general contractors that generates instant job quotes based on labor hours, material costs, and regional rates. Handles appointment booking confirmations, sends customer reminders, tracks outstanding invoices, and provides daily job summary reports — all without leaving Telegram.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
